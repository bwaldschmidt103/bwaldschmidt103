### 🛠️ The Portfolio Build
This live portfolio showcases my front-end development and design capabilities. Here is a breakdown of how it was built:

- **Architecture:** Engineered with **React** and modern **JavaScript (ES6+)** using semantic **HTML** and **CSS3/SCSS** for structural integrity.
- **Styling & Layout:** Built using **Bootstrap** with a heavy focus on **Responsive Web Design**, explicit **Layout Systems**, and proper **Visual Hierarchy**.
- **Design System:** Prototypes and wireframes designed in **Figma**, leveraging custom asset pipelines from **Adobe Creative Cloud** and **Affinity**.
- **Inclusivity & Standards:** Developed strictly against **Web Accessibility (WCAG)** standards and optimized for **Cross-Browser Compatibility**.
- **Data & APIs:** Integrated dynamic data handling using asynchronous **REST APIs**.
